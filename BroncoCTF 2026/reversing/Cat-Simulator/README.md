## Background
Reverse engineering (reversing) is the process of analyzing a compiled 
binary to understand what it does without access to the source code. 
Tools like Ghidra or Dogbolt can decompile binaries back into 
readable pseudocode.

In this challenge you'll need to understand how the program tracks 
game state and figure out the exact conditions required to unlock 
the real flag.
