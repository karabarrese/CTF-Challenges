# Lovely Login

## Intended Difficulty: Easy

## Description

Welcome to our lovely new login page 💕
The developers swear it’s secure… but they may have forgotten to clean up a few things before launch.
Can you figure out how authentication works and log in as the right user?

## Background
Web challenges in CTFs often involve finding information that 
developers accidentally left exposed — hidden pages, misconfigured 
files, or endpoints that never got cleaned up before launch.

`robots.txt` is a standard file that tells search engine crawlers 
which pages not to index. Ironically, listing pages there often 
draws more attention to them than hiding them ever could.

This challenge also explores one of the oldest mistakes in 
security: thinking that obscurity equals protection. Just because 
something isn't obvious doesn't mean it's safe.

---

## Inspiration
I wanted to build the least secure login page imaginable while 
still making it feel like something a real developer might actually 
ship. Real vulnerabilities often come from small oversights. I think 
it's more fun to learn about security mistakes when they're wrapped in 
something that feels plausible and a little silly.
